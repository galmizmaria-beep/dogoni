# Догони, если сможешь

Браузерный редактор учебной игры-догонялки.

## Что реализовано
- интерактивное окно предпросмотра и тест игры;
- сохранение проекта в JSON, загрузка проекта и локальное автосохранение;
- экспорт автономной HTML-игры;
- облегчённый HTML и копирование iframe-кода для Genially;
- загрузка героя, противника, трёх слоёв параллакс-фона, бонусов и препятствий;
- автоматическое уменьшение PNG/JPG/WebP, а для GIF — перекодирование при поддержке браузером с безопасным fallback;
- управление стрелками: движение, прыжок и пригибание;
- препятствия, бонусы, жизни, таймер и скорость преследователя;
- задания: один ответ, несколько ответов, устный ответ, порядок, ввод ответа;
- неверный ответ уменьшает жизнь и приближает противника;
- победа только после сбора всех бонусов при наличии хотя бы одной жизни;
- языки интерфейса: RU, EN, DE, ES, FR, IT, PT, PL, TR, UK;
- настройка цветов, шрифта, размера текста и скругления окна задания;
- подпись об авторских правах присутствует только в редакторе.

## Nono GIF
В открытых источниках не обнаружен подтверждённый публичный API сервиса с названием «Nono GIF». Поэтому сейчас предусмотрены загрузка GIF и вставка прямой GIF-ссылки. При наличии документации/API Nono интеграция может быть заменена адаптером без изменения структуры проекта.

Откройте `index.html` через GitHub Pages или обычный веб-сервер.
